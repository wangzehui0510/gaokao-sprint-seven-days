## 2. 表现与制作原则

1. **动作靠轮廓和道具辨认。** 写字、翻书、漫画、进食、游戏、扫地、健身、洗漱分别有可读的手部和身体运动；状态名保留作准确说明。
2. **多数行为独立设计关键姿态。** 同类动作可以共享头部、校服、腿部和基础骨架，冲刺、预习、笔记、自测、考试仍分别设计节奏与道具，不能全部交付同一段写字循环。
3. **同义和强化行为按变体制作。** 基础/物品漫画、普通/强化橡皮、普通/强化偷书可以共享主动作，靠封面、道具和短特效区分。宿舍磨蹭复用卧床主体，增加翻身或赖床变化。
4. **长行为采用“进入→主循环→退出”，互动增加双方回应。** 通常进入和退出4～6帧、主循环4～8帧；具体数量随动作可读性调整。不是每项都必须新画完整的进入/退出，起坐、递接、转身等过渡可以共用。
5. **瞬时动作只做短反馈。** 专注指令、举报、每日点、物品奖励使用短动作/表情/图标，不制作几分钟的持续施法表现。
6. **动画跟随真实结果。** 发起被拒绝不播放成功动作；中断不播放完成收益；胜负、物品消耗、知识与纪律分仍由现有执行器决定。

下表帧数为每段、每个参与角色、每个所需方向的建议；不是合计工时。B1～B4是交付顺序，全部属于表现优先方案，后批次也要完成。

## 4. 全部21项双人持续行为

双人不是一张两人合并大图。建议分别交付发起者、目标的角色帧与道具，记录接触点/座位点，以支持任意两名角色组合。近身动作需要统一互动站位；远距投掷继续使用真实双方位置。

| 序号 | 行为与ID | 建议双方演出 | 主段帧数、复用与制作顺序 |
| --- | --- | --- | --- |
| 01 | 提醒或叫醒同学 `remind_friend` | 发起者轻拍/示意，目标回头或揉眼坐直 | B3；发起6帧＋回应4～6帧，目标按实际原姿态选择回应 |
| 02 | 一起解题讲题 `solve_together` | 一人指题讲解、另一人听和写，适当轮换 | B3；双方各6～8帧，同桌合作；共享写字基础，独立讲解手势 |
| 03 | 扔纸条聊天 `send_note` | 写/折纸、抛出，目标接住；真实送达后才能展开 | B3；发起6帧＋接收4～6帧，纸条2～4帧飞行；未完成不得出现已送达正文 |
| 04 | 邀去操场玩 `invite_playground` | 招手邀请，到操场后两人配合玩耍 | B3；邀请4～6帧＋双方6～8帧循环，复用单人玩耍动作并补双方配合 |
| 05 | 相约食堂 `invite_canteen` | 邀请、同桌进食、短暂交流 | B3；复用双方吃饭6～8帧，加4帧交流变化；不默认存在相互投喂 |
| 06 | 借阅笔记 `borrow_notes` | 发起者伸手，目标递笔记，再对照阅读 | B3；递接双方各6帧＋阅读4～6帧，完成结果再出现笔记加成反馈 |
| 07 | 投喂零食 `feed_snack` | 发起者递食物，目标接过/入口、咀嚼 | B3；双方各6～8帧；物品来自发起者，恢复结果属于目标 |
| 08 | 击掌鼓劲 `encourage` | 互相示意、抬手、击掌、振作 | B3；双方各6～8帧，接触帧对齐，短闪光独立于人物 |
| 09 | 抢答挑战 `answer_challenge` | 双方思考与举手，真实结算后分别表现胜/负/平 | B3；思考4帧、举手6帧、结果各4～6帧；没有真实结果前保持待判定 |
| 10 | 弹橡皮捣乱 `eraser_prank` | 瞄准蓄力、弹出，目标命中后缩肩/回头 | B3；发起6～8帧＋目标受击4帧；命中反应只跟随真实完成 |
| 11 | 偷换课本 `swap_book` | 观察、伸手换封面/课本，目标翻书困惑 | B3；发起6～8帧＋回应4～6帧；错科目图标跟随真实状态与选科 |
| 12 | 掰手腕 `arm_wrestle` | 对坐握手、发力僵持，真实结果后压倒/松手 | B3；双方各6～8帧＋胜负平4～6帧；需桌面握手锚点，不从动画力度推算胜负 |
| 13 | 枕头大战 `pillow_fight` | 互相举枕、挥动、格挡/躲闪 | B3；双方各8帧，可复用一套经核验的左右姿态；无逐击业务结果时不逐击弹扣分 |
| 14 | 强化弹橡皮 `use_eraser` | 沿用弹橡皮动作，增加物品使用和更清楚的命中反馈 | B3；共享主动作，补道具/闪光变体；不另画完整第二套身体动作 |

| 16 | 递漫画给同学 `give_comic_item` | 递出、接收，双方阅读/分享漫画 | B3；递接各4～6帧＋阅读6～8帧；当前不在同桌集合，新站位需客户端接入 |
| 17 | 给同学清凉糖 `give_candy_item` | 递糖、接糖、目标吃糖后清醒 | B3；双方各4～6帧，复用递接和吃糖基础；发起者不一起消耗/进食 |
| 18 | 合伙恶作剧 `prank_together` | 两人间的调皮试探/戏弄，目标分心回应，发起者放松 | B3；双方各6～8帧；按已实现的两人互动设计，不画第三名受害者或三人协同 |
| 19 | 抢走漫画 `take_comic` | 起始抢夺/制止阅读，目标被打断；完成后分心 | B3；双方各6～8帧；仅表现短暂抢夺动作，不画进入发起者背包、加库存或返还消耗物 |
| 20 | 结伴自习 `study_together` | 两人同桌读同科材料，互相指题、记录 | B3；双方各6～8帧，共享宿舍自习基础，独立补交流段 |
| 21 | 室友开黑 `roommate_game` | 两人操作同类设备、相互示意、短暂共同反应 | B3；双方各6～8帧，共享单人游戏身体基础；没有比赛胜负数据，不编造胜利结算 |

现有`TOGETHER_ACTIONS`只包含一起解题、邀去操场、相约食堂、结伴自习、室友开黑。其他近身动作目前主要用箭头表达。新增拍肩、击掌、掰手腕、递物、抢书等画面，必须同步设计站位与遮挡，不能只把两套动画放在相隔很远的原座位上。

## 5. 两项瞬时行为与非动作事件

| 行为/事件 | 需要的美术表现 | 是否独立身体循环 |
| --- | --- | --- |
| 专注指令 `focus_command` | 坐直/回神短段、专注图标或短光效；收益文字读取真实值 | 不需要持续循环；可共享回神过渡 |
| 举报开小差 `report` | 举手/示意短段、举报标记；目标按真实动作返回课表 | 不需要持续循环，不制作持续举报施法 |
| 任课教师在场 | 三位教师各自待机4帧、讲课6～8帧、板书6～8帧；按课程变化切换教师 | 需要；讲课面向学生，板书面向黑板 |
| 主任抽查 | 主任观察4～6帧；进门、离开与学生被发现的短反应 | 需要；进出/行走属于拟新增视觉接入，抽查结算时点保持现有规则 |
| 每日属性点、每日物品 | 点数图标、5种物品小图、短弹出/飘字 | 无独立身体循环；不新增抽卡成功演出或假奖励 |
| 日榜、考试出分、七天终局 | 真实名次/成绩对应的短庆祝、泄气、平静或结果图标 | 共享结果短段；不把无结果/缺科画成获胜 |
| 动作开始/取消/中断 | 起坐、转身、收道具、打断标记 | 共用过渡库；中断只收束，不播完成特效 |

教师素材本期建议覆盖：任课老师3人各“待机/讲课/板书”3段，主任“观察/进出”动作；行走按实际需要增加方向。音乐、美术、体育当前没有对应新老师在场逻辑，不直接扩成九科教师制作单。

### 13种状态的表现

状态通常挂图标和短反应，不为每个状态增加独立身体主循环。效果和持续时间读取权威状态。

| 状态 | 推荐表现 |
| --- | --- |
| 拿错课本 `wrong_book`、加长版 `wrong_book_boost` | 错科目书本/问号，强化版换边框；状态到期移除 |
| 冲刺 `sprinting` | 专注符号/速度笔触，与冲刺动作配套 |
| 心中有数 `prepared`、笔记清晰 `notes_ready`、借到好笔记 `note_borrowed` | 准备、笔记、借阅三种图标，允许共享书本底形 |
| 思路打开 `inspired` | 灯泡或短顿悟光效 |
| 意犹未尽 `comic_afterglow`、分心 `distracted` | 漫画回想/走神符号；与正在读漫画区分 |
| 斗志昂扬 `encouraged`、有点泄气 `discouraged` | 上扬/下垂情绪图标与短表情 |
| 身体舒展 `stretched`、身体疲惫 `tired` | 舒展与汗滴/疲惫符号；不能擅自改变当前动作 |

### 道具与环境配套

- **背包5类**：橡皮、零食、恶作剧书套、漫画杂志、清凉糖。每类分别交UI图标与场景小图；场景图尺寸按手部和桌面比例确定，不直接缩放UI大图。
- **动作工具**：课本、笔/转笔、笔记本、试卷、画纸、乐谱、餐盘/餐具、扫帚、枕头、毛巾/牙刷、游戏设备、训练道具；后四类的具体选择先确认。
- **短特效**：纸条飞行/展开、橡皮旋转/命中、击掌亮点、轻灰尘、汗滴、困意、清醒、思考、错科目、胜负平、打断、抽查警示。只有真实橡皮完成才触发橡皮命中；其他互动拥有自己的反馈。
- **家具与场景**：教室保持风格基准；食堂补可用座位/餐桌遮挡，宿舍补床面/被子前景及桌椅工作位，操场安排运动与双人活动空间。洗漱是否需要新增局部设施随方案确认，不默认扩第五个大场景。
- **行走和过渡**：学生四方向行走各6～8帧、起坐/转身/就位各4～6帧；教师方向按路线需求制作。当前游戏没有连续寻路，位移表现与路径接入单列评估。

## 6. 统一交付规范

### 画面与方向

- 沿用斜俯视正交、16×16环境网格、384×256场景画布。学生基准单帧32×48，站姿/桌边脚点为(16,44)，透明背景、最近邻和整数倍显示。
- **教室学习基准朝北**，与现有黑板位置一致；食堂当前也朝北。宿舍当前左右角色分别朝西/东，操场当前朝南/东。不能按旧提案直接把所有宿舍循环只画南向后宣称可直接接入。
- 建议按场景座位确定必要朝向：课堂北向，宿舍与近身互动按最终工位补东西向，移动南东北西4向。是否保留这些机位或调整宿舍工位待确认；暂不默认全部动作做8方向。
- 左右镜像需要逐项检查：持笔手、文字、校徽、单边发饰和道具不能未经核验直接翻转。三科书本可用封面/图标变化，不需要每科重画整套身体。
- 卧躺、俯卧撑、挥枕头等可能超出站姿画布；先出姿态样片，再确定专用画布和锚点。允许专用尺寸并记录元数据，禁止非整数拉伸或裁掉动作以硬套32×48。

### 分层与文件

建议交付目录为`assets/pixel/<角色>/animations/<动作>/<方向>/`，另有共享`props/`和`fx/`。这是新交付提案，不迁移或覆盖现有资产。

每段包括：

1. 可编辑Aseprite源文件，明确身体、手臂、道具、表情、前后景图层。
2. 定尺寸逐帧PNG或图集，透明边保留；导出方式在样片阶段统一。
3. 动画元数据：动作ID、角色/方向、单帧尺寸、原点/脚点、手部接触点、每帧时长、循环段、进入/退出段、分层顺序及道具挂点。
4. 双人额外记录：发起者/目标角色、相对站位、握手/击掌/递接接触点、双方同步帧、动作被打断时的收束方式。
5. 1x/2x场景合成预览、循环预览与验收状态；完整帧和拆层帧标清，避免叠两次手。

建议静态/呼吸4帧、主要循环6～8帧；安静动作约2～4帧/秒，进食/游戏/运动约6～8帧/秒，短反应按动作节拍设计。现有数十秒到45分钟等不同业务时长由循环覆盖，不能把一分钟行为画成一次一分钟的慢动作。

## 7. 制作与接入批次

| 批次 | 内容 | 验收后再扩展 |
| --- | --- | --- |
| B0：统一基准与样片 | 确认角色外观、方向、道具；先做正常学习、偷看漫画、宿舍游戏、卧床、弹橡皮、结伴自习6个样片 | 确认尺寸、锚点、桌床遮挡、双人接触点、帧节奏及四人同时活动的可读性；样片选中的动作提前制作 |
| B1：课堂高频 | 学习、发呆、趴睡、漫画、零食、冲刺、考试、休息、醒来；教师讲课/板书和主任观察 | 教室1x/2x合成，四人不同动作同时播放，手和道具不穿桌 |
| B2：生活与户外 | 宿舍自习/刷题/游戏/健身/洗漱/卧床，食堂吃饭、体育训练、课间操、操场玩耍；必要家具/场景资产 | 修正教室外仅站姿的接入；工作位与家具匹配，卧床能真实被床面遮挡 |
| B3：完整双人 | 全21项互动的双方动作、递接/飞行道具、近身站位、真实结果短段 | 任意角色组合、交换发起者/目标、同桌/近身/远距、中断、真实胜负平和隐藏恢复 |
| B4：细分与过渡 | 预习/笔记/自测、眼操、音乐/美术、站立听课、值日、偷懒、磨蹭、回神/离返场细节 | 60项逐条回看，补齐方向、强化变体、状态图标、移动过渡及场景小细节 |

首批样片建议以`student01`建立一套可验收基准；其余学生是否同时扩展造型由用户确认。若最终制作四名独立学生，角色动画仍需要逐人适配，不能把调色或同一成片重复计作四套独立角色。

### 工作量口径

- 单人按“独立动作设计×角色数×所需方向×帧数”统计，再单列进入/退出与变体。
- 双人按发起者和目标分别计段数；21项互动不等于21张图。相同角色库可组合，避免为每一对角色再绘制合并大图。
- 例如6帧动作：一名角色一个方向为6张身体帧；四名角色两个方向为48张，尚不含进出、表情、道具和结果。8帧动作对应8张/64张。
- 动作表中的普通/强化共享、单人/结伴共享只减少可复用部分；新增交流、目标反应、站位验收仍有工作量。
- 未确认角色数量、方向、特殊画布与设备前，不给“总共多少张/几天完成”的固定承诺。B0后据通过样片的实际产出确定整批预算。

## 8. 必须配合的客户端表现工作

这部分是后续接入需求，不在本次盘点中改代码：

1. 把当前“study/daydream/sleep/standing”四种粗映射扩成动作与场景/方向的明确映射，支持不同帧数、分段与角色外观。所需资产未完成时明确列为待制作，不将统一站姿验收为完成。
2. 让操场、食堂、宿舍能够播放专用循环；卧床、桌边、健身、洗漱各有正确工位，命中区域、标签和选中框跟随呈现位置。
3. 新增近身互动站位与双方同步，保留同桌合作、远距纸条/橡皮的不同表现。双方不同地点时按真实位置展示，不画跨场景隔空接触。
4. 桌、椅、床前景和人物分层验收。当前完整教室底图加完整坐姿可以支持既有样本，不能据此假设所有大幅手臂、起立与躺卧动作都能直接接入。
5. 表现层读取动作开始、在途、完成、中断及真实结果；任何动画接触帧都不负责扣物、加分、改变随机流。纸条飞行可采用更短的视觉段，但送达提示始终等真实完成。
6. 视觉位移不延迟已经生效的业务状态，不新增移动费用、冷却或强制等待。真实地点与视觉过渡的关系需要在样片接入时明确，不能把画面路线当成新增寻路规则。
7. 托盘隐藏仍只停视觉；恢复显示当前真实动作，不补播已过期的受击、送达、胜负、奖励。

“表现优先”和主要循环4～8帧已经确认。下列事项尚未确认，本方案给出推荐供开工时选择，未据此修改实现：

| 决策 | 推荐 | 其他选择/影响 |
| --- | --- | --- |
| 学生外观 | 先批准四名学生的站姿设定，再用学生01完成B0样片并扩展 | 也可整版先保留同一造型；角色数量直接影响整批动画量 |
| 动作方向与工位 | 保留课堂北向；先确定宿舍桌床机位，再制作所需东西/北向；行走四向 | 若改为统一朝向，需要配套调整工位/场景；全八向成本另计 |
| 游戏/运动/健身/洗漱道具 | 建议先各选一种：游戏设备一种、体育训练一种、操场娱乐一种、健身一种、洗漱一种 | 手机/掌机/电脑、跑步/拉伸、球类、哑铃/俯卧撑、毛巾/刷牙等不能同时默认全部制作 |

## 10. 每批美术验收

- 60个动作ID均有明确映射；“已有/新制/复用变体/待确认”可区分，强化版和瞬时动作不遗漏。
- 1x无需动作文字也能看出主要行为差异；2x保持像素边缘清楚，关键动作不被姓名标签遮住。
- 每帧尺寸、脚点、头部体积和地面位置稳定，循环首尾衔接；卧床等特殊锚点单独记录。
- 坐姿是真实坐姿，卧床是真实卧躺，手部与桌面/床面/道具关系正确；没有用隐藏腿部冒充动作。
- 双人角色分别可替换，交换双方后接触点仍对齐；四人同时互动不重叠穿模，近身动作不会隔空发生。
- 正常完成、中断、胜负平、缺结果、切镜头、终局、托盘隐藏恢复分别查看；只有真实完成才出现相应成功反馈。
- 每段有可编辑源文件、可重复导出PNG、元数据和场景预览；不把生成草稿或未接入素材标成已验收。
