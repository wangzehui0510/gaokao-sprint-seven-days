## 七天账本与计分

唯一`ClassroomSimulation`仍持有角色、动作、资源、知识、随机流和日志；`RoundProgression`只接收真实知识增量并维护纯事件账本，不建立第二份收益来源。`config/phase_scope.json`当前标识为`phase_6_pair_expansion`，在阶段5原18项与17项个人规则上增加14项双人规则，共49项；自主候选仍保持原范围。

当前课表每天16:40发布当天四科新增知识榜；语文、数学、英语在第7天14:00、14:55、15:55开考，各45分钟结束公布。体育在14:00首场开考时即时取值公布，16:40发布最终榜。这些时刻从正式课表解析：每日最后课程结束是日榜截止，末日第一场考试开考是体育取值，末日最后课程结束是终局；没有另写一套固定时间表。

单科公式：`X = K × (1 + C × I)`，`S = M × [1 - exp(-X / T)]`，按开考保存的小数位四舍五入。当前C=0.03，语数英满分150/T=180，体育满分50/T=140，各科保留1位。每科先舍入后相加；不同历史精度用共同整数刻度精确求总分。内存刻度为int64，JSON编码十进制字符串，覆盖超过2^53的奇数往返。有效智力或有限成绩为负仍忠实采用公式，不静默钳制；超出实际表示范围明确失败。

知识榜按未舍入增量排序，成绩按保存的整数刻度排序；并列使用1、1、3，不消耗随机数。已快照科目保存K/I/M/T/C、精度、配置来源与时刻，之后互动、状态变化或调表不重算历史。UI逐科使用历史精度，总榜使用其保存的共同精度。

同一边界的顺序为：真实积分 → 恰好到期动作完成 → 定时状态到期 → 换课清理动作状态 → 开考/公布/日榜/终局 → 尚未结束才继续决策。恰好16:40完成的纸条正常送达，仍未完成的取消，不发完成奖励。

完整课表在配置入口校验，缺课、重叠、重复时段/课节、越界日、非课程引用、末日缺考试或提前考试明确拒绝。热改先整体预检，尚待事件不能移到已观察的过去；合法未来时刻、费率及未取值参数仍可改，已发生历史保持原样。局内天数和知识科目身份不兼容变动拒绝。跨配置读档先按退出时原计划和冻结参数处理离线纯事件，再做新配置兼容预检，成功后才替换有效局。

v4顶层包含`round_progression`，存储每日增量/榜单、考试、最终榜、冻结来源和已观察最远边界。合法开发时钟回退保留历史，未来伪记录、损坏或自相矛盾的新版账本拒绝，不降级成旧档缺史。JSON普通浮点比较只容许表示误差，整数成绩始终精确比较。

核心只读接口返回深拷贝：

- `is_round_finished()`、`get_round_summary()`：状态、天数、真实`final_day/final_seconds`。
- `get_daily_board(day, subject)`：`pending/published/unrecorded`、统计区间、来源、原因和四人增量/名次。
- `get_exam_board(subject)`：`pending/snapshot/published/unrecorded`、开考/公布边界、来源和保存的计分行。
- `get_final_board()`：`pending/published/incomplete`、缺科及原因、总分/整数刻度/精度/各科成绩与名次。

`load_file_at_time(path, day, seconds)`是权威恢复入口，供隔离验收显式恢复时间，复用生产冻结读档链，不修改电脑日期；它会恢复局状态，不属于只读查询。

## 桌面与玩家操作

原五页人物/课表/记录/互动/背包保持索引0至4，榜单追加索引5。设置“查看榜单”打开第六页，类型、日期、科目筛选只查看保存记录，不改资源、库存、随机流、日志、纸条收件人或各自草稿。未公布考试只显示快照状态；缺史和离线来源可见，长记录滚动，刷新保留筛选与阅读位置。终局禁用新指令与右键互动，原草稿和只读页面保留。

1x主块384×320、2x主块768×576；左栏292像素、间隔8像素，展开尺寸仍684×320和1068×576，六页不改变这些尺寸。四场景384×256按整数倍显示，四人暂复用同一外观。人物页分开显示基础/有效属性、真实状态和剩余时间，并可分配本人初始点；背包显示真实正数量库存，本人可选择三项自用动作，同学只读。

右键其他同学身体或座位姓名弹出224×180小面板，提供纸条、基础橡皮、“更多…”和举报；“更多…”与基础橡皮同行，打开固定目标的14项双人选择器。互动页也有同一入口，普通/强化明确选择，偷换课本显式选科，真实点击“开始互动”才发动。左键只查看人物，不改变弹窗目标或纸条会话。

纸条打开对应会话，填写发送才发动，正常完成才送达；草稿按收件人暂存、失败保留、成功只清对应草稿、换局清空。基础橡皮无需物品。双人动作任一参与者离开就整体打断，保留已发生效果、不退费或已扣物、不发未完成奖励，旧搭档回课表，旧事件不能覆盖新动作。

举报绑定打开右键面板时的违纪ID，同一事件只结算一次；过期不自动改报新事件。举报当前搭档采用用户批准例外：整体结束旧互动、目标强制回课程，举报者按正常课表自然重新选择，未完成纸条不送达。外点/Esc关闭且不透传，方向键/Tab焦点限于面板；布局变化、托盘隐藏、换局和可见错误关闭旧面板。

每日物品仍为四人各自按局内日一次，只有成功开始当前课程默认`study/physical_study/music_class/art_class/exam`才按配置领取，当前抽3次且允许重复。睡觉/发呆/非课程不计，低资源等实际回课后领，跳日不补，回退不重领。统一规划完整抽取和库存叠加后提交库存、领取日、随机流与真实日志；数量溢出明确失败，不加背包业务上限。

数值权威为Excel→JSON。后续费率调表立即生效，当前已抽时长不变、不重扣启动费。专注每次生效并重建学习段、无点击次数限制；免费基础休息保留。体育低专注自主候选`playground_play`启动专注费用为0；音乐/美术只恢复、不长知识。NPC自主互坑仍未开放。

## 窗口生命周期与保存

关闭按钮和系统关闭请求收进Windows托盘，四人继续在线活动；真正退出位于托盘“退出游戏”。原生辅助程序`tools/native/DesktopWindowBridge.cs`核验HWND与进程归属，通过`ShowWindowAsync`执行并用Win32状态确认成功，不能用最小化或引擎visible假装隐藏。

`hide_to_tray()`和`restore_window()`是协程，必须await；Godot工作线程等待辅助程序，主线程逐帧继续处理消息与唯一模拟器。退出先等在途原生操作，再保存当前局和窗口偏好，全部成功才清理托盘退出。保存失败保留进程、恢复窗口并显示错误。窗口控制器不持有第二份游戏状态，重试桌面初始化不新建局。

配置/存档/状态不变量错误停止权威结算并保留修复入口；资源不足、过期举报等普通拒绝及窗口偏好错误可见，但不停止原有效局。初始化失败不能从旧缓存假装成功。运行中的旧进程不自动加载源码，更新后需先保存退出再启动。

正式用户目录：`%APPDATA%\Godot\app_userdata\高考冲刺七天\`。正式`classroom_save.json`、开发`classroom_debug_save.json`、窗口`desktop_settings.json`分别保存。本轮没有读写正式用户存档，也没有启动正式游戏制造测试夹具；测试局只在独立缓存或隔离应用运行。
