# 角色AI升级设计方案

版本0.3，2026年11月9日。定位：**联机挂机游戏，四个角色最终都是真人朋友，没有NPC；"AI"是每个角色离线/挂机时的自动驾驶，行为倾向由该玩家自己的属性加点决定。** 本地单机阶段，小林/小陈/小周只是用预设加点模拟未来真人的占位假人。

## 先看结论

1. AI 不是"NPC个性"，是**挂机自动驾驶**：同一套 AI，在线玩家手动指令优先，离线/挂机时按自己的加点自动运行。
2. 行为倾向统一由四属性（自律性、健康、专注力、智力）驱动——**玩家的加点即塑造角色的挂机风格**，这是最终形态。
3. 宿舍六项从"等概率"改为"倾向+保底"：属性加权偏移，但每项保留最小概率下限，不会消失。
4. 补弱科口径 = **当前累计知识量最低**的文化课，选科按"倾向+保底"加权。
5. 课堂自主池开放已配表的`read_comic`、`bathroom`；`send_note`仍仅玩家发起。
6. 挂机角色可自主发起**竞争性互动**去干扰对手、提升自己名次：动作池为纯竞争利己型（借笔记 + 偷换课本/邀请操场食堂/掰手腕/橡皮恶作剧），目标按"领先加权随机"，发起频率属性驱动；**无托管/在线边界，打断在线玩家是有意玩法**。
7. 情绪/好感度持久状态、特殊事件本轮不做。

本轮不引入新的持久化字段：加权全部从已保存的属性、知识、地点和互动推导，存档版本维持v4，不新增第二份角色数值。

## 一、挂机自动驾驶的定位

每个真人角色在两种状态之间切换，共用同一套行为树：

| 状态 | 行为 | 入口 |
| --- | --- | --- |
| 在线（玩家操作中） | 手动指令优先，随时打断自动行为 | 玩家指令入口 + 同一执行器 |
| 挂机（离线/离开） | 按属性加点自动运行 | 行为树自主决策 |

"角色接着做什么"始终由同一执行器结算，只有"谁在驱动"不同：在线是玩家，挂机是加点驱动的自动驾驶。

## 二、属性驱动加权（加点即行为倾向）

四属性在权威配置中已存在，本轮直接把行为倾向绑定到它们，不新增人格轴表：

| 属性 | 现有作用 | 挂机行为倾向 |
| --- | --- | --- |
| `discipline` 自律性 | 决定最大专注 | 勤奋：学习/自习/刷题↑，发呆/游戏/磨蹭↓，开小差阈值↓；自律越低越爱发起竞争干扰 |
| `health` 健康 | 决定最大体力 | 好动：健身/操场/课间操↑ |
| `attention` 专注力 | 决定知识效率 | 已在积分生效；决策上影响专注恢复偏好 |
| `intelligence` 智力 | 决定考试加成 | 已在计分生效；决策上轻微放大学习类权重 |

"贪玩"取自律性的反向。所有加权来自同一份权威属性，读档天然一致。

归一化采用配置参考值（新增全局`personality_ref_attr`，默认取初始点上限8），单属性归一值`a = effective_attribute / ref`：

```
final_weight = config_weight × (1 + axis_gain × a)
```

`axis_gain`与`personality_ref_attr`作为新全局参数维护进Excel。

### build 平衡原则

不同加点方向都要好玩、可行，不能某一种 build 碾压。每个属性轴既有收益也有代价，`axis_gain`取值需保证任一点法下六项宿舍活动与课堂候选都仍可被选到（保底），且考试总分上不存在单一最优加点。数值调优以"build 多样性"为验收口径。

## 三、宿舍活动加权（倾向+保底）

替换已批准的"六项等概率"为属性加权，但每项保留下限。

1. 以当前六项各权重1作为基线。
2. 属性倾斜：

| 活动 | 属性 | 倾向公式 |
| --- | --- | --- |
| `dorm_study` / `dorm_practice` | 自律性+智力 | `1 + g_study×a_discipline` |
| `dorm_game` | 反向自律 | `1 + g_game×(1 − a_discipline)` |
| `dorm_workout` | 健康 | `1 + g_workout×a_health` |
| `dorm_wash` / `dorm_rest` | 无 | 保持1（保底基线） |

3. 保底：加权后归一化，任一可执行活动的最终概率低于配置下限（新增全局`dorm_weight_floor`，建议0.05）时抬高到下限并重新归一。资源耗尽导致某项不可执行时，先移出候选再对其余做保底归一。

## 四、补弱科与选科（知识量最低）

自习/刷题等`knowledge_mode == "selected_subject"`的动作，选科时按"倾向+保底"偏向**当前累计知识量最低**的文化课（语文/数学/英语）：

1. 从已保存的`student.knowledge`取三科累计值，最小者为弱科。
2. 弱科权重`1 + g_weak`，其余两科权重1。
3. 三科同样做保底归一（沿用`dorm_weight_floor`），并列最小用同一随机流任选，不额外抽数。

口径只依赖已保存知识，不新增弱科目标存储。

## 五、课堂自主池（补已配表缺口）

`phase_scope.auto_actions`从`["daydream","sleep"]`扩为`["daydream","sleep","read_comic","bathroom"]`：

| 文化课低专注候选 | 权重 | 属性倾斜 |
| --- | ---: | --- |
| `daydream` | 40 | `1 + g×a_playful` |
| `read_comic` | 25 | `1 + g×a_playful` |
| `bathroom` | 15 | 中性 |
| （体育）`playground_play` | 10 | `1 + g×a_health` |

`send_note`保持仅玩家发起。开小差阈值`distraction_focus_threshold`按自律性微调：`有效阈值 = 50 × (1 − k_threshold × a_discipline)`。

## 六、竞争自主社交（干扰对手、提升名次）

挂机角色自主发起的双人互动是有意的竞争手段——打断对手学习、为自己争取名次。**无"托管/在线"边界**，可对任意角色（含正在操作的真人）发起，打断在线玩家是有意玩法。

### 动作池（纯竞争利己型）

| 类型 | 动作 | 效果 |
| --- | --- | --- |
| 利己 | `borrow_notes` 借笔记 | 发起者得到笔记加成（知识倍率1.2） |
| 干扰 | `swap_book` 偷换课本 | 让对方学错科目，知识记到错误科目 |
| 干扰 | `invite_playground` 邀请去操场 | 把对方拉出课堂，错过当前课 |
| 干扰 | `invite_canteen` 邀请去食堂 | 把对方拉出课堂，错过当前课 |
| 干扰 | `arm_wrestle` 掰手腕 | 消耗双方体力，影响对方后续学习 |
| 干扰 | `eraser_prank` 橡皮恶作剧 | 让对方分心 |

### 发起条件与频率

- 当前为知识课（考试、课外时段不发起），发起者当前动作为空、体力不低于睡觉阈值。
- 发起概率由属性驱动：自律越低越爱发起干扰（`social_auto_base × (1 + g×(1−a_discipline))`）。

### 目标选择（领先加权随机）

1. 先过滤满足`start_interaction`前置的目标（同场景、双方费用可支付、非自己）。
2. 对剩余目标按"领先程度"加权随机：领先者（当前累计总知识更高）权重更高，但不是必选，保留随机性。
3. 领先度量与补弱科口径一致，用当前累计总知识；权重曲线（如`w = 1 + g_lead × 领先归一值`）由Excel全局系数控制。

### 选科（`swap_book`）

自主发起时随机选一个不同于目标当前授课科目的文化课；是否优化为"选对方已掌握科目以最大化干扰"作为后续数值调优点，本轮不引入。

### 架构变化

现有树只提交个人`start_action`；新增"选目标+选互动"叶子，提交叶子按选择类型分流到`start_action`或`start_interaction`。互动沿用现有`interactions`存档，发起者已由`initiator_index`记录；日志`reason`标注"自主干扰"。

无人为冷却：频率由决策边界、前置校验、发起概率天然限制。

## 七、本地占位假人加点（开发/演示用，联机后删除）

本地单机阶段没有真人朋友，用预设加点模拟未来真人。新增配置（Excel）`npc_attributes`，在`setup()`时给三位占位假人分配初始8点；玩家"我"保留8点自由分配：

| 占位角色 | attention | discipline | health | intelligence | 模拟的性格 |
| --- | ---: | ---: | ---: | ---: | --- |
| 小林 | 1 | 4 | 1 | 2 | 学霸：自律高、智力高 |
| 小陈 | 2 | 1 | 3 | 2 | 贪玩：自律低、好动 |
| 小周 | 2 | 1 | 5 | 0 | 好动：健康极高 |

预设消耗占位假人自己的初始待分配点，`unspent_points`相应归零。这是**本地演示占位**，联机后由真人自己加点，不属于最终玩法；与延后的"NPC每日自动加点"是两回事。

## 八、实现边界与验收

1. 配置经Excel新增全局`personality_ref_attr / dorm_weight_floor / social_auto_base`及各`axis_gain / g_lead`系数，新增`npc_attributes`表（联机后移除）；导出后校验不改变既有57动作、课表与计分。
2. 加权逻辑集中在行为树选择节点与`get_auto_candidates / get_dorm_candidates`内，保持"权重来自配表+属性修正"可回溯；`can_start_action / can_start_interaction`边界不变。
3. 不新增静默兜底：候选为空、目标不满足、费用不足仍明确报错/跳过并留日志。
4. 存档维持v4，不加字段；热改与新配置语义冲突时沿用现有原子校验。
5. 验收覆盖：四人差异化决策、宿舍保底不被击穿、弱科选科、课堂三候选、竞争互动目标选择（领先加权+属性频率）、终局/换课/资源耗尽边界、读档往返与热改。
