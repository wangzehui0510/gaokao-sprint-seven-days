## 桌椅分层与写字

各层按同一64×64画布原点绘制：`layers_v1/desk_back.png` → `chair_base.png` → `animation_v1/curated/frame_*.png` → `layers_v1/chair_front.png`。桌面纸张归桌层，手持笔归人物层，椅背在人物前景。

`layers_v1/all_furniture.png`是真实局部重绘后恢复的空桌椅。原可见家具逐像素保留，人物原本挡住的桌面、椅面由PixelLab补全；人物mask漏掉的3个头发边缘像素又经过一次真实局部重绘修正。空家具三层重组和批准座位四层重组均为0 RGBA像素差异。完整遮罩、两次回执及逐像素清单见该目录的`README.md`和`layer_manifest.json`。

`animation_v1/raw/`保留一次真实整段生成的7帧，未修改原稿。生成稿存在头部、身体和脚部漂移；最终按源帧`0,6,4,2,4,6`整理为六帧往返循环，逐帧时长`280,150,160,200,160,150`毫秒，完整循环1100毫秒。固定批准源的头、领口、身体、臀腿与脚，仅采用右前臂、手和笔的真实生成像素；少数新增抗锯齿色显式归到批准源调色板，身侧两像素连接保持批准源。所有变化都在动作union mask内，家具不随动画变化。规则、来源摘要、色值映射和逐帧检查见`animation_v1/curation.json`。

空教室使用PixelLab `create_image_pro`任务`9242bf7c-2b09-4267-a075-111cfbfb317f`，15 generations；整段写字原稿使用`animate_image`任务`51e7f97e-e979-4fa1-9f82-f375d5a9bc3d`，1 generation；空家具与3像素清理为两次真实局部重绘，合计10 generations。子目录日志保留各次完整请求与回执。

## 重建与边界

依次使用带Pillow的Python执行`animation_v1/build_animation.py`和`build_preview.py`。脚本依赖明确的最终PNG与mask，不自动选择其他批次或静默缩放；重新生成素材后须重新运行隔离GPU检查。`layers_v1/build_layers.py`可重建分层，运行方式见其说明。

人物只包含批准视角真实可见部分，被椅背挡住的人体尚未补全；适用于固定坐姿的小幅写字，不能直接用于起立、转身或移动。四个预览角色暂共用学生01外观与相位。教师、其他动作、双人位置、命中区域与正式资源索引尚未适配；父目录`.gdignore`继续隔离素材制作目录。本轮未改变正式玩法、权威配置与存档。
