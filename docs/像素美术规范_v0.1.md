# 复古像素美术规范

版本0.1，2026年11月6日。用于《高考冲刺七天》首名学生与教室样本。

## 已确定的画面方式

采用斜俯视正交视角。地面横纵线平行，桌椅不向远处缩小，不采用等距菱形地砖。角色可以看到少量头顶，同时保留南向站姿的脸部和身体。

场景源文件尺寸与产品横竖屏分别决定。本次384×256是美术画布，不代表已确定设备、窗口尺寸或界面排布。

## 共用像素尺寸

| 对象 | 源像素尺寸 | 说明 |
| --- | --- | --- |
| 基础地砖 | 16×16 | 环境布置网格。 |
| 角色单帧 | 32×48 | 透明画布，各方向保持相同尺寸。 |
| 基准角色可见高度 | 南向40，其余38～39 | 以不透明轮廓测量；朝向带来的轮廓差异保留，不拉伸。 |
| 基准角色可见宽度 | 约20～24 | 不同朝向轮廓可不同；不拉伸角色补宽。 |
| 角色脚底锚点 | (16,44) | 画布坐标从0开始，脚底轮廓结束于y=43；底部留4像素。 |
| 角色碰撞参考 | 12×8 | 以脚底为中心的地面占位，属于接入建议，需和实际动作姿态核对。 |
| 教室画布 | 384×256 | 24×16个基础网格。 |
| 北墙可见高度 | 48 | 墙脚固定y=48；其下为地板。 |
| 门框／门内净高 | 46／42 | 门框从y=2到47，内门从y=4到45，门口接通地面路径。 |
| 学生桌椅预留单元 | 64×48 | 含横向留白；实际家具图形为48×48，精确范围另存布局配置。 |
| 学生桌面宽度 | 48 | 桌腿、挡板和桌面共同构成约24像素的可见桌高。 |
| 普通通道净宽 | 至少32 | 主要通道更宽，便于纸条飞行和双人互动演出。 |

角色生成结果如果偏离规格，先记录原始轮廓，再做明确的像素编辑与脚底对齐。不能通过非整数缩放把素材勉强塞进框内。

## 四人教室构图

黑板居北墙中央，窗在左侧区域，门在右上区域，前方为讲台活动区。四个学生座位按两列、两排布置，横向中心x=112与272；两排模块的参考范围分别为y=96～143与176～223。最终精确矩形和锚点以教室目录内的布局JSON为准。

四个学生座位是主要活动区域。装饰不能变成额外的学生座位，也不能挡住中间走道、座位旁路和门口。教师讲台可用不同形态单独识别。

首名角色先交付站姿。坐着学习、趴桌、转笔、看漫画属于后续独立状态；不把站姿下半身藏在桌后当成坐姿。座位锚点只预留位置，不代表已制作相应坐姿。

## 层级与遮挡

背景包含地板、墙面、黑板、门窗及固定装饰。桌与椅分别保存为独立图层和图片，不烘焙进唯一背景，也不共用一个排序脚点。角色与可排序家具按地面脚点决定前后；桌前局部遮挡图层用于坐姿和桌边动作。

只对真实覆盖人物的桌面或挡板使用遮挡区，不能把整张桌椅图反复盖在所有人物上。手部、纸条、橡皮等道具和表情分别叠加；瞬时举报不使用持续施法条。

## 像素与颜色

使用清楚的单像素轮廓和少量明暗层次。人物使用蓝白校服、深色头发与少量肤色；环境使用浅灰地砖、薄荷白墙、黑板绿，木桌只作为局部暖色。主体与环境需保留明度差。

源PNG保持原始像素尺寸。预览允许2倍、3倍等整数倍最近邻放大；不增加抗锯齿、不用平滑滤镜。界面文字在游戏接入时另行排版，不画进场景背景。

## 本次素材记录

角色原图由PixelLab Pro Flash生成，原始32×48PNG保留不覆盖。生成请求目标可见高度38～40，实测原始轮廓20×44；通过有记录的像素行编辑与平移规范到40像素，再用于四方向生成。

教室首先由PixelLab Pixen生成384×256草稿。草稿出现8张学生课桌、透视收缩及过高墙面，没有通过四人布局验收，因此改用Aseprite按精确坐标绘制；草稿作为风格参考保存。

角色四方向由规范化南向图交给PixelLab V3参考旋转生成，角色ID为`a8e45275-522e-4afa-ac11-e00c05c684a8`。原生输出仍为32×48，南向像素与输入参考一致。背面整体下移1像素，其余方向不移动、不缩放。四方向统一脚底锚点(16,44)，方向修正记录见`assets/pixel/student01/direction_alignment.json`。

最终教室使用真实Aseprite 1.3.18.6的Lua像素绘制接口生成，源文件15图层：地面、墙体、固定装饰，以及四组桌主体、椅子和局部前景。源文件重新打开导出的PNG与交付教室逐像素一致。绘制脚本保存在`tools/draw_classroom.lua`，后续可以直接在Aseprite编辑图层，也可修改脚本后重新生成。

本次不生成其他三名学生，不制作学习或坐姿动画，不把同一角色重复放置的比例预览记为四名不同角色。

## 验收与接入

- 人物透明画布、可见轮廓、脚底锚点分别检查，不只检查PNG宽高。
- 四方向保持同一服装、发色和像素密度；任何对齐修正需记录，不静默拉伸。
- 教室恰好四个学生座位，横向桌宽与纵向排距一致。
- 北墙48像素、地砖16像素节奏清楚，门口和通道连通。
- PNG与分层Aseprite源文件一并保留；最终导出以源文件可重复生成。
- 组合预览只用于检查比例与层级，不代表已经实现游戏状态、寻路或联机。

教室拆分PNG全部保留384×256画布，`image_origin`为(0,0)，不能把透明边自动裁掉后仍沿用原始坐标。`module_bounds`描述64×48预留空间，`art_bounds`描述48×48实际图形；桌面图像高度包含投影，不等同于物理尺寸。桌使用`depth_anchor`，椅子使用`chair_depth_anchor`分别排序。`layout.json`中的碰撞和坐姿预留只是接入参考，后续需随专用姿态在游戏内验收。

若直接预览本次房间，建议使用2倍或3倍整数显示，对应768×512或1152×768。产品窗口、横竖屏和界面区尺寸仍单独设计。
