版本1.2，2026年11月8日。阶段1至5，以及上一轮本人初始属性点分配、四场景、17项个人执行规则与其中16项主动入口均保留。本轮接通14项规则明确的玩家双人扩展，阶段标识`phase_6_pair_expansion`，共49项执行动作；后台与好友联机继续后置。玩法存档仍为v4，显式兼容v1至v3及旧v4基础互动。当前25组30352项断言与18张实际GPU截图结果和验收边界见`继续开发交接.md`，桌面布局与操作见`桌面迷你教室_v0.1.md`。

用户已确认三条规则：退出期间只按保存的冻结知识/智力/参数补纯事件，不产生离线收益；旧档保留进度并明确标注缺史；第7天16:40结束本局，保留查阅、保存和手动重开。它们均已接入，不重复询问。七天结算依据见`阶段5实施方案_v0.1.md`，当前阶段范围见`继续开发交接.md`。

## 已确认方向

- 首发目标为Windows桌面迷你教室，可拖动、置顶和收起到托盘；本机Godot实际版本为4.7.2 stable。
- 先完成本地单人操作版，后台服务器与真人联机后续开发。
- 教室内四名角色共用一套行为树，全部自主活动，各自拥有独立运行状态。
- 玩家只向自己的角色下主动指令，可以选择同学作为互动对象。
- 继续采用现有策划、Excel导出的JSON和斜俯视正交像素素材。
- 新局按电脑当前时间进入课表；读档重新对齐电脑日期与时间，进程真正退出期间不补算收益。关闭窗口收进托盘后仍在线运行，四人继续自主活动和自动保存。
- 导出的配置可在运行中重新读取，后续消耗与恢复立即使用新值，已抽取的动作时长保持不变。

## 启动与操作

当前工程文件为项目根目录的`project.godot`，主场景为`scenes/main.tscn`。已在本机Godot 4.7.2 stable执行编辑器导入和真实规则检查。

`main.gd`和窗口设置已采用迷你教室布局。原生隐藏/恢复由`tools/native/DesktopWindowBridge.cs`核验真实窗口句柄与进程归属后执行，游戏主线程继续处理Windows消息和唯一模拟器；不使用主窗口`hide()/show()`冒充成功。完整发布包、多DPI、多屏及睡眠唤醒仍需后续验收。

在`K:\高考冲刺挂机`打开PowerShell运行：

```powershell
& .\tools\start_game.ps1
```

进入Godot编辑器查看工程：

```powershell
& .\tools\start_game.ps1 -Editor
```

当前目录结构下启动脚本默认使用`K:\godot\Godot_v4.7.2-stable_win64_console.exe`。启动前自动运行`tools/native/build_bridge.ps1`，用.NET Framework C#编译器生成无辅助控制台的Win32桥接；缺失编译器或构建失败时明确停止。更换引擎安装位置时显式指定，不会自动搜索或改用其他版本：

```powershell
& .\tools\start_game.ps1 -GodotPath 'K:\godot\Godot_v4.7.2-stable_win64_console.exe'
```

当前桌面布局为：1倍显示384×256场景，包含上下各32像素工具栏的主块为384×320；2倍主块为768×576。人物、当天课表、班级记录、互动、背包和榜单在左侧292像素临时面板查看，间隔8像素，展开时增加300像素宽度。窗口位置、置顶和缩放偏好单独保存。

- 左键点击教室角色或人物面板名单，只改变查看对象并展开详情。
- 右键其他同学的身体或座位姓名打开窗口内部的小面板；本人和空地不弹他人互动。面板绑定该同学，打开本身不扣费、不改动作，也不展开左栏或改变窗口尺寸。
- 底部行动栏中的专注、休息、睡觉始终作用于自己的角色。
- 点击黑板或课表入口，查看由当前正式JSON生成的当天课表。
- 顶栏场景选项默认“跟随我”，随本人真实课表或动作地点观察教室、操场、食堂、宿舍；也可固定观察其中一处。切镜头不移动角色，不改变查看对象、纸条收件人与草稿。
- 人物页“+”打开本人四属性面板，每次消费一个现有待分配点。提高资源上限不补满当前值，已保存考试快照不重算；同学详情只读，终局禁加点。
- 左栏“背包”入口打开第五页，索引4；人物/课表/记录/互动的0至3索引保留。当前查看角色的正数量库存、名称与描述均来自真实状态，空包显示“暂无物品”。本人可选择零食、漫画或清凉糖自用，成功开始才扣物；同学库存只读。查看和切选项本身不发奖、不扣物，也不改变纸条收件人与草稿。
- 设置菜单“查看榜单”打开第六页，索引5。可筛选每日四科知识榜、各科考试和最终榜，查看统计区间、取值来源与缺失原因；未公布考试只显示快照状态。内容滚动查看，保留原收件人与草稿。
- 人物页分开显示基础与有效属性，真实生效状态显示配置名称、修正、说明和定时剩余或“随当前动作结束”；状态列表可滚动，倒计时刷新保留滚动位置，切换对象重新定位。
- 右键面板的“发纸条…”打开对应会话并聚焦输入，填写后发送或回车才发动；“弹橡皮”和“举报”直接提交真实指令。“更多…”与“弹橡皮”同行，保持224×180面板尺寸，打开14项双人动作选择器。原详情顶部“互动”、第四个选项卡和对象下拉框继续保留。草稿按收件人暂存于当前界面，显式切换会话保留各自文字，查看人物或打开菜单不转移草稿；成功发动后只清空对应草稿，失败保留，完成后才进入真实会话。草稿不写玩法存档，换局清空。
- 互动页“更多…”也打开双人动作选择器，目标在打开时固定，独立于人物详情和纸条收件人。普通/强化明确选择，偷换课本必须显式选另一门文化课，当前科目禁选；查看费用、状态与可用性不扣物，点击“开始互动”才提交。取消、布局、隐藏、换局或错误关闭后，旧目标失效，过期点击不发动。
- 右键举报固定打开时的事件编号；旧事件结束或已处理后，不自动改报后来一次违纪，重新右键才绑定新事件。面板外点击与Esc关闭，外部点击不透传；布局变化、托盘隐藏、换局及可见错误关闭旧面板。
- 专注每次点击均按配表增加专注；上课中重新进入当前课程并抽取新动作时长，学习中重复点击也生效。
- 底栏书本图标打开“我的行动”，选择已开放的个人主动动作后查看真实费用和效果，点击开始才发动。16项主动动作均作用于本人；自主来源的`linger_break`仅接入执行器，不新增玩家入口或自主候选频率。
- 顶部提供保存、置顶、缩放和关闭工具；设置菜单提供重新读取配表、重新开始、开发工具及重试桌面功能。
- “重新开始”需要界面确认，随后创建新班级并替换正式进度。
- 关闭窗口收进Windows托盘，四人继续自主活动；从托盘恢复窗口，点击托盘菜单“退出游戏”保存并真正退出。更新代码后需先退出正在运行的旧进程，再运行启动脚本。

正常开局若正处于晚上或课外时段，角色会依课表休息。观察上课循环可使用下面的开发时钟，不需要修改电脑时间。

## 开发时钟

打开“设置 → 开发工具”，点击“开发时钟：第1天 08:00”。入口先保存正式进度，再建立独立的第1天早课测试局；顶部会标记“[开发]”。

填写“推进分钟”后点击“推进”，会经过正常执行器完成时间积分、动作结束和课表切换。该入口不直接赠送知识、资源、奖励或伪造事件。开发时钟仍会随程序实际运行时间继续走动。

点击“回到电脑时间”会保存开发局，再读取正式存档并对齐当前电脑时间。开发局与正式局分文件保存；开发入口每次建立新测试局，不自动恢复上次开发局。

## 配表与热更新

数值源为`outputs/01a1aebc-daa9-7ca0-9b2c-d4652fa3194d/高考冲刺七天_配置_v0.2.xlsx`，游戏实际读取`config/game_config.json`。字段和导出规范见`config/配置维护说明.md`；运行中的生效策略以本节为准。

1. 修改并保存Excel；当前已接入动作的时长、消耗、恢复和知识速度均可由配表调整。
2. 在项目根目录执行`& .\tools\导出配置.ps1`，确认导出成功。修改Excel本身不会触发游戏更新。
3. 游戏每约1秒检查JSON修改时间，也可点击“设置 → 重新读取配表”。成功后详情面板状态栏显示“配表已更新”，班级记录写入配置变化。
4. 后续结算立即采用新费率。已有动作不重新扣启动费、不重新抽时长；已发生的收益与结果不重算。时长区间变化作用于下一次启动的动作，资源上限变化按新上限调整当前资源。

热更新还会检查当前权威状态：删除背包已引用的物品或生效状态、改变生效状态的定时/随动作持续方式、让生效状态互斥组发生冲突、使生效偷换状态的知识重定向不兼容均明确拒绝，不替换有效配置。名称、描述与已支持数值继续读取当前配置，不能静默丢弃持有物品或替换状态来迁就调表。

`config/phase_scope.json`以`phase_6_pair_expansion`声明本地单机的49项执行范围；自主候选仍保持已确认范围，完整Excel中尚未接入的动作不会因为导出而自动开放。新增效果类型、互动流程或场景需要同步开发执行器与表现，不能只新增配表行就当作已实现。

导出器或游戏读取配置失败会明确报错。导出失败时旧JSON仍在，但不代表本次修改成功；游戏读取失败时停止结算并显示错误，修正后可从菜单重新读取，不会静默套用一套默认数值。

## 存档语义

- 正式进度为`user://classroom_save.json`，开发进度为`user://classroom_debug_save.json`。Windows默认目录为`%APPDATA%\Godot\app_userdata\高考冲刺七天\`。
- 运行中约每30秒自动保存，也可点击顶部保存按钮。关闭只收进托盘，真正退出由托盘菜单触发；逐帧等在途窗口操作结束，游戏和窗口偏好均保存成功后才清理托盘退出。失败时恢复窗口、显示错误并保留现场。
- 窗口管理器使用`user://desktop_settings.json`保存位置、1倍/2倍和置顶，不与玩法进度或Excel配表混用。窗口/偏好错误不停止原本有效的权威模拟器；游戏/存档错误保留原失败恢复链。
- 新写入版本为`save_version: 4`，保存四人状态、已抽动作时长与进度、随机状态、状态到期与日志，以及共同互动关联、已送达纸条、连续违纪和处理状态、七天账本与冻结来源；每人保留升序、唯一正整数的`daily_item_claim_days`。读档不重新抽当前动作、不重复扣启动费、扣物、送达、举报或领取每日物品；缺损或矛盾记录在覆盖有效局前明确拒绝。JSON载入后领取日归一为整数，开发时钟回退也保留全部已领日。
- 双人记录保存`selected_subject_id`、`stamina_snapshot`和`result`，偷换状态保存实际选科，掰手腕保存扣费前双方体力与真实完成胜负。旧v4纸条/基础橡皮缺少全部三项时显式迁移为空元数据；其他部分缺字段、扩展必需信息缺失或矛盾结果明确拒绝，不能猜科目、快照或胜负。
- v1至v3旧档迁移保留原进度，v2/v3保留原互动关联，v3保留原领取日；仅v1/v2建立空领取日，不按库存猜历史。缺失日榜和开考快照明确标“未记录”，迁移当天从接入时统计。后续保存采用v4；新档损坏账本拒绝读取，不降级成旧档缺史。
- 读档按本局创建日期计算第几天，再对齐电脑当前时刻。真正退出期间不补资源、知识或完成奖励；若已跨课，旧动作按打断处理，再由行为树选择当前时段动作。
- 同一课程内重新打开时保留已存动作的剩余执行进度；真正退出的时间不计入该动作执行时长。托盘隐藏期间，唯一模拟器继续按真实运行时间结算，仅停止人物视觉动画。
- 当前局不锁定旧配置。读档使用当前有效配置的后续费率，保留已发生结果与已抽时长；不兼容或损坏的存档会明确报错，不伪造新局作为读取成功。
- 状态实例必须与当前配置生命周期一致，定时到期时间、动作归属及互斥组关联均通过校验；未刷新/替换的重复组明确拒绝。定时状态沿用原到期时刻，真正退出期间不消耗剩余在线时长，恢复后在原在线执行边界结束。
- 每日物品先在临时随机流规划全部抽取并检查库存累加，再统一提交库存、领取日、随机流和真实日志。日志记录领取日、课程动作、每抽的奖池行/物品/数量及汇总；不因调表、重复专注、回退日期或查看背包重领。抽数、是否放回、权重与数量读取配置，非法配置明确拒绝，不静默换奖池。

## 第一阶段的目标

做出一个能持续运行、能看懂、能操作、能保存的教室版本。首先验证“自主学习→开小差/恢复→被互动打断→回到课表”的实际循环。

先以一个正常课程窗口完成纵向验证，再扩展全天和七天流程。首轮不要求52个动作全部完成，不以四个场景同时铺开作为开工目标。

## 四人共用行为树

共享的是行为树定义；四个角色分别运行各自的树实例和黑板。黑板保存角色ID、目标及决策上下文，资源和背包以角色状态为唯一来源，不复制为另一份权威数据。

行为树不是数值执行器，不自行扣资源、发奖励或操作动画。行为树选择动作后向统一执行器提交请求；玩家的主动指令也提交到同一入口。

自主流程沿用现有策划：

1. 课表边界、动作完成或合法打断先更新当前动作状态。
2. 当前动作仍有效且执行中，继续执行，不重新抽时长或随机候选。
3. 到自主决策点时解析当前课程/时段；知识课按体力、专注等规则选择睡觉、开小差或学习。
4. 音乐、美术及非上课时段按既有恢复与课表规则执行。

学习段的5～10分钟只在启动时抽取一次。专注严格低于50的判断发生在自主决策点，不能每帧用阈值强制重开动作。

玩家每次点击专注，执行器按规则结算旧动作、增加专注并建立新的课程活动段。行为树读到这个运行中的动作后继续执行；无需新增冷却、保护时段或手动锁。课程边界、专注与已开放互动统一走打断链。瞬时举报通常保持举报者动作；举报当前搭档时按上述用户批准的例外整体结束旧互动，再自然选择举报者的新动作。

当前其余三名同学按已确定的课表与自主规则活动，并真实参与玩家发起的基础互动及本轮14项扩展。自主发起哪些双人互动、目标如何选择及频率，仍属于待确认的AI策略，不在开发时暗中添加。

## 首轮必须保留的玩法语义

- 健康是属性，体力是资源；最大专注依自律性，最大体力依健康。
- 动作时长、消耗、恢复、发生阶段和比例均读取配表，不在行为树节点写死数值。
- 发动、持续、完成、瞬时分开处理；只结算真实执行的时间。
- 基础休息免发动成本，不能另设避免资源耗尽的隐式赠送或恢复路径。
- 专注指令每次生效，学习中重复点击也重新抽时长；不重复收自然入段费。
- 学习知识只在有效知识课程窗口增长，音乐与美术只按恢复课程规则处理。
- 随机时长、当前动作、参与者和已结算时刻需要入档，不能读档后重新抽取。
- 配置错误、物品不足和动作不满足条件必须可见，不能静默换动作或显示假成功。
